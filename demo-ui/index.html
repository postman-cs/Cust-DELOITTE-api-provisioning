AdminStep 3 of 10

Invite Guard

Every provisioned workspace gets an invite policy. Invites are domain-scoped — no one can invite gmail.com even with admin access.

Provision a workspace first (Step 1).
GET /invite/workspace/:id/policy
View auto-created invite policy
ALLOWEDInvite bob@coca-cola.com (partner domain)
BLOCKEDInvite hacker@gmail.com (free email)
PARTIALMixed: legit@coca-cola.com + bad@yahoo.com

Compliance Guardrails

The security floor: global rules that no one can go below, plus team overrides that can only tighten.

Collection Protection & PR Workflow

Protect the Cloud Platform APIs v3 collection

POST /collections/pr/:id/review
Review the PR (self-review blocked)
